# Şablon ve Kılavuz

- `referans.docx` — Enstitünün Word tez şablonu. Bu adla konursa `scripts/word-uret.sh` başlık, paragraf ve kenar boşluğu stillerini buradan alır.
- Enstitü yazım kılavuzu (PDF) — buraya konur, kuralları `CLAUDE.md` dosyasına özetlenir.
- `apa.csl`, `ieee.csl` — kaynak gösterme stilleri. `metadata.yaml` içindeki `csl:` satırı hangisinin kullanılacağını belirler.
