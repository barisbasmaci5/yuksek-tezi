| Fourier dönüşümlü kızılötesi spektroskopisi | Fourier-transform infrared spectroscopy | FTIR | |
| Taramalı elektron mikroskobu | Scanning electron microscope | SEM | |
| Kalsiyum silikat hidrat | Calcium silicate hydrate | C-S-H | Çimento kimyası gösterimi |
| Portlandit (kalsiyum hidroksit) | Portlandite | CH | Çimento kimyası gösterimi |
